# نظام الحضور الذكي — مشروع أندرويد

هذا مجلد مشروع Android Studio، وليس ملف APK جاهزاً. يحتوي على واجهة HTML محلية داخل التطبيق، وتخزين محلي في WebView، وماسح QR بالكاميرا.

## بناء APK
1. نزّل وثبّت Android Studio على كمبيوتر.
2. افتح Android Studio واختر **Open** ثم مجلد `smart_attendance_android`.
3. انتظر مزامنة Gradle وتنزيل المكتبات.
4. من القائمة اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. عند اكتمال البناء، سيظهر رابط موقع ملف APK داخل نافذة الإشعار.

## كيف يعمل مسح QR؟
- أضف الطالب واجعل حقل **رقم الطالب** يطابق النص المخزّن داخل QR.
- اضغط زر إعداد/مسح QR داخل التطبيق واسمح للكاميرا.
- عند مسح رمز يحمل رقم الطالب، يُسجَّل حضوره.
- هذه النسخة تتعامل مع نص QR المطابق لرقم الطالب أو معرّف الطالب أو اسمه.

## حفظ البيانات والخصوصية
- البيانات محفوظة محلياً في مساحة تخزين المتصفح داخل التطبيق.
- لا توجد مزامنة سحابية أو حسابات مستخدمين.
- لا تحذف بيانات التطبيق أو تمسح بياناته من إعدادات أندرويد، وإلا قد تفقد سجلات الطلاب.

## ملاحظة
يلزم بناء المشروع عبر Android Studio لإنشاء APK موقّع/قابل للتثبيت. لم يتم تضمين APK جاهز في هذا الملف.
